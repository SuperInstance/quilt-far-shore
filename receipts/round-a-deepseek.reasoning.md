- Definition: A set of registerable operators over quilt-chrono ledgers — `diff(cell, dimension, window)`, `integrate(flow, t1, t2)`, `lag(a,b)` — computed as pure reductions over the append-only flow entries. Each yields a new cell whose value is the derived quantity, not a stored event.

- Naive failure mode: Naive discrete differences amplify write noise and late-arriving ledger entries; without bucketing/staleness bounds, a derivative cell oscillates under small jitter and triggers false interventions.

2. ### Moment Field — continuous vector array
- Definition: A learned/linear interpolation over named vector dimensions {warmth, urgency, familiarity, frustration,...} that returns a continuous value plus gradient for any vector point, not only near bucketed region centroids. It stores sparse anchor regions and a distance metric; soft joints query the field rather than a bucketed table.
- Unlocks: Operators get gradients — how a ruling or tone changes per unit frustration or urgency — as an object; freezing becomes a statement about field flatness, not bucket occupancy.
- Grows from: quilt-softjoints bucketed vector regions; delta: replaces discrete buckets with an interpolated manifold and exposes field gradients.
- Naive failure mode: If distance metric is global Euclidean, correlated dimensions (urgency-frustration) create interpolation across semantically empty regions, making a cell appear confident in a moment the system has never seen.

3. ### Evidence Key — fact/emotion splitting
- Definition: A deterministic projection from raw inputs to a typed fact vector {receipt_present, amount, item_count, date, channel} that lives beside the emotional vector. Region keys and freezing tests may only use Evidence Key dimensions for outcome-bearing branches; the emotional vector may only modulate tone, persona, or escalation.

- Grows from: quilt-storefront’s failed refund freeze and its diagnosis; delta: makes fact dimensions explicit and first-class in region keys.
- Naive failure mode: If evidence extraction is a model call rather than deterministic receipt/schema checks, it reproduces the soft-joint ambiguity one layer down and the region still won’t freeze.

4. ### Greeter Contract — sealed human boundary
- Definition: A cell marked as greeter carries a signed contract with three mandatory parts: allowed inputs, non-decomposed decision space, and handoff triggers to automated cells. The compiler and freezing test treat it as a forbidden region: no lookup promotion, no automatic adjustment compilation across its boundary.
- Unlocks: Operators gain a legally/commercially protected "no decomposition" object; greeter cells become auditable boundaries rather than vague exceptions.
- Grows from: greeter cells concept; delta: formal contract, sealing, and compiler-enforced non-decomposition.
